# Local-only dev tooling for the browser DevUI (the "option 2" chat UI).
#
# IMPORTANT: install this into a SEPARATE virtual environment, not the main
# .venv. DevUI requires agent-framework-core >= 1.9, which conflicts with the
# pinned agent-dev-cli (< 1.3.0) in requirements.txt. Keeping them apart leaves
# the main .venv matching the deployed image.
#
#   py -m venv .venv-devui
#   .\.venv-devui\Scripts\python.exe -m pip install -r requirements-dev.txt
#   .\.venv-devui\Scripts\python.exe devui_local.py   # -> http://localhost:8090
#
# None of this ships to Foundry — the hosted image installs requirements.txt only.
